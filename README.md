# ノベルゲームエディタ

テキスト＋選択肢分岐、立ち絵・背景画像、BGM・効果音・ボイス、変数/フラグ管理に対応した
ノベルゲームを作成できるデスクトップアプリ（Electron製）です。
作成した作品は「セーブ機能つきの単体で再生できるゲーム（HTML一式）」として出力できます。

## 動作環境

- Node.js 18以上を推奨（開発・ビルド時のみ必要。書き出したゲーム自体はブラウザだけで動きます）

## セットアップ

```bash
npm install
npm start
```

`npm start` でエディタが起動します。

## 使い方

1. 起動画面で「新しいプロジェクトを作成」→ 保存先フォルダとタイトルを指定
2. 左側の「シーン一覧」でシーンを追加・選択
3. 中央の「＋ コマンドを追加」から、セリフ・背景変更・立ち絵表示・BGM再生・
   選択肢・変数変更・シーン移動などを組み立ててシナリオを作成
   - 立ち絵/背景/BGM/SE/ボイスは、各コマンドの「素材を追加…」ボタン、または
     右側パネルの「素材」タブから取り込めます（プロジェクトフォルダ内の `assets/` に保存されます）
   - 「変数/フラグ」タブで好感度やフラグなどを定義し、選択肢の表示条件
     （例: `favorability >= 3`）やジャンプの条件に使えます
4. 上部の「▶ テストプレイ」でいつでも実際の画面で動作確認ができます
5. 「⇩ 出力（エクスポート）」で、選択肢したフォルダにゲーム一式（`index.html` ＋
   `assets/` ＋ `js/`）が書き出されます。ZIPでまとめて出力することも可能です。
   書き出したフォルダの `index.html` をブラウザで開くだけでそのまま遊べます。

## セーブ機能について

書き出したゲームは、タイトル画面の「はじめから／つづきから／ロード」と、
ゲーム画面右上の「セーブ／ロード」から、12個のセーブスロットに保存・読込ができます。
セーブデータはブラウザの `localStorage` に保存されます（作品ごとに独立したキーを使用）。
万一 `localStorage` が使えない環境でも、アプリが落ちないようにその場限りのメモリ上の
保存に自動的に切り替わるようになっています。

## 配布用の実行ファイル（Windows .exe）を作りたい場合

```bash
npm run dist
```

`electron-builder` により `dist/` フォルダに、Windows向けの
インストーラー版（`.exe`、アイコンつきでスタートメニュー/デスクトップにショートカットを作成）と、
インストール不要でそのまま起動できるポータブル版（`.exe`）の2種類が生成されます。
（Mac/Linux向けのビルド設定も残していますが、`npm run dist`はWindows向けのみをビルドします）

## GitHubで公開して、他の人がダウンロードしてすぐ使えるようにする

このリポジトリには `.github/workflows/build.yml` を用意してあり、GitHubに push した後
バージョンタグ（例: `v1.0.0`）を push すると、GitHub Actions上でWindows向けの実行ファイルが
自動ビルドされ、GitHubの「Releases」ページに `.exe`（インストーラー版・ポータブル版）が
自動で添付されます。他の人はNode.jsやこのソースコード一式を用意しなくても、
Releasesページから `.exe` をダウンロードしてダブルクリックするだけで使えます。

手順の例:

```bash
git add .
git commit -m "初回コミット"
git remote add origin https://github.com/(あなたのユーザー名)/(リポジトリ名).git
git push -u origin main

git tag v1.0.0
git push origin v1.0.0
```

タグをpushするとActionsタブでビルドが始まり、数分後にReleasesページに実行ファイルが並びます。
（Actionsタブから手動で「Run workflow」を実行して、ビルドだけ試すことも可能です。この場合はReleasesには公開されず、ビルド結果はActionsの実行結果からダウンロードできます。）

もし公開に失敗する場合は、`package.json` に以下のように自分のリポジトリ情報を追記してみてください。

```json
"repository": "https://github.com/(あなたのユーザー名)/(リポジトリ名)"
```

## フォルダ構成

```
main/              Electronメインプロセス（ウィンドウ管理・ファイルI/O・書き出し処理）
renderer/          エディタ本体のUI（HTML/CSS/JS）
player-template/   書き出されるノベルゲーム本体（ランタイム/セーブ機能を含む）
build/             アプリのアイコン（icon.png / icon.ico）
.github/workflows/ GitHub Actionsでの自動ビルド設定
test/engine.test.js  ランタイムの自動テスト（`npm run test:engine` で実行。テスト自身が
                     サンプルプロジェクトを一時的に生成するため、追加の準備は不要）
```

## シナリオデータの仕様（拡張の参考に）

プロジェクトは `project.json` として保存され、シーンはコマンドの配列で構成されます。
対応コマンド: `text`（セリフ/地の文）, `bg`（背景）, `char_show`/`char_hide`（立ち絵）,
`bgm_play`/`bgm_stop`, `se_play`, `voice_play`, `set_var`（変数操作）, `choice`（選択肢分岐）,
`jump`（条件付きシーン移動）, `end`（終了）。
条件式・値の式は変数名がそのまま使えるJavaScript式です（例: `favorability >= 3 && flag_a`）。
