# ノベルゲームエディタ

テキスト＋選択肢分岐、立ち絵・背景画像、BGM・効果音・ボイス、変数/フラグ管理に対応した
ノベルゲームを作成できるデスクトップアプリです。作った作品は、セーブ機能つきの
単体で再生できるゲーム（ブラウザで開くだけで遊べるHTML一式）として書き出せます。

## インストール方法

Node.jsなどのインストールは不要です。以下の手順だけで使えます。

1. このリポジトリの **[Releases](../../releases)** ページを開く
2. 最新バージョンの中から、次のどちらかをダウンロードする
   - **`ノベルゲームエディタ-Setup-x.x.x.exe`**（インストーラー版）
     ダブルクリックすると案内に沿ってインストールされ、スタートメニューと
     デスクトップにショートカットが作成されます。特にこだわりがなければこちらを推奨します。
   - **`ノベルゲームエディタ-x.x.x-portable.exe`**（ポータブル版）
     インストール不要で、ダウンロードした`.exe`をダブルクリックするだけでそのまま起動します。
     USBメモリなどに入れて持ち運びたい場合や、インストールせずに試したい場合はこちら。
3. ダウンロードしたファイルを実行する

## アプリの開き方

- **インストーラー版を選んだ場合**：インストール完了後、デスクトップまたはスタートメニューの
  「ノベルゲームエディタ」アイコンをダブルクリックして起動します。
- **ポータブル版を選んだ場合**：ダウンロードした`.exe`ファイルをダブルクリックすると、
  そのまま起動します（次回以降も同じファイルをダブルクリックすればOKです）。

起動すると、最初に「新しいプロジェクトを作成」「既存のプロジェクトを開く」を選ぶ画面が表示されます。

## 使い方（操作説明）

### 1. プロジェクトを作る

「新しいプロジェクトを作成」を押し、保存先フォルダと作品タイトルを入力すると、
そのフォルダの中にプロジェクト一式（`project.json`と`assets`フォルダ）が作られます。
一度作ったプロジェクトは、次回以降「既存のプロジェクトを開く」からその`project.json`を
選べば続きから編集できます。

### 2. 画面の構成

| エリア | 内容 |
| --- | --- |
| 左側「シーン一覧」 | シーン（場面）の一覧。＋ボタンで追加、クリックで選択・編集対象を切り替え |
| 中央「シーンエディタ」 | 選択中のシーンの中身を、コマンド（命令）を上から順に並べて作成する場所 |
| 右側パネル | 素材・キャラクター・変数/フラグ・作品情報をタブで切り替えて管理 |
| 上部ツールバー | 新規作成・開く・保存・テストプレイ・出力（エクスポート） |

### 3. シナリオを組み立てる（コマンド）

中央エリアの「＋ コマンドを追加」から、以下の命令を組み合わせてシナリオを作ります。
追加したコマンドをクリックすると詳細設定が開き、上下ボタンで並び替え、削除ボタンで削除できます。

- **💬 セリフ・地の文**：話者名（空欄なら地の文）と本文を入力。ボイスも指定可能
- **🖼️ 背景を変更**：背景画像を切り替え（フェード／瞬時切り替えを選択可）
- **🧍 立ち絵を表示 / 🚶 立ち絵を退場**：キャラクターの表情差分画像を左・中央・右のいずれかに表示／非表示
- **🎵 BGMを再生 / 🔇 BGMを停止**：ループ再生やフェードイン・フェードアウトの秒数を指定
- **🔔 効果音を再生 / 🗣️ ボイスを再生**：単発の音声を再生
- **🔢 変数を変更**：好感度やフラグなどの変数を `=` `+=` `-=` `*=` `/=` `toggle` で操作
- **🔀 選択肢を表示**：複数の選択肢と、それぞれの移動先シーン、表示条件（例: `favorability >= 3`）を設定
- **↪️ シーン移動（ジャンプ）**：条件つき・条件なしで別のシーンへ移動
- **🏁 ゲーム終了**：エンディングを表示してタイトル画面へ戻る

条件式・変数の値には、変数名がそのまま使えるシンプルな式が書けます
（例: `favorability >= 3 && flag_a == true`）。

### 4. 素材を取り込む

右側パネルの「素材」タブ、または各コマンドの「素材を追加…」ボタンから、
背景・立ち絵・BGM・効果音・ボイスの画像／音声ファイルを取り込めます。
取り込んだファイルはプロジェクトフォルダ内の`assets/`にコピーされ、各コマンドの
プルダウンから選べるようになります。

### 5. キャラクター・変数/フラグ・作品情報

- 「キャラクター」タブ：立ち絵コマンドで使うキャラクターのID・表示名を登録
- 「変数/フラグ」タブ：好感度やフラグなどを名前・種類（数値／真偽値／文字列）・初期値つきで登録
- 「作品情報」タブ：タイトル・作者名・バージョン・開始シーンを設定

### 6. テストプレイと出力

- 上部の **「▶ テストプレイ」** を押すと、その場でシナリオを実際にプレイして確認できます
- 上部の **「⇩ 出力（エクスポート）」** を押すと、出力先フォルダを選ぶだけで、
  そのまま配布・公開できるゲーム一式（`index.html`＋`assets/`＋`js/`）が書き出されます。
  ZIPでまとめて出力するかどうかも選べます。書き出したフォルダの`index.html`を
  ブラウザで開くだけで、そのまま遊べます。

## 作ったゲームの遊び方・セーブ機能について

出力したゲームの`index.html`を開くとタイトル画面が表示され、
「はじめから」「つづきから」「ロード」を選べます。ゲーム画面右上の
「セーブ」「ロード」ボタンから、12個のセーブスロットにいつでも保存・読み込みができます。
セーブデータはブラウザ内（`localStorage`）に保存されるため、同じブラウザ・同じ`index.html`を
開けば続きから遊べます（万一保存ができない環境でも、アプリが落ちないよう一時的な
メモリ上の保存に自動的に切り替わります）。

## トラブルシューティング

- **「WindowsによってPCが保護されました」と表示される**
  このアプリはコード署名（証明書によるデジタル署名）をしていないため、Windowsの
  SmartScreenという保護機能が初回起動時に警告を出すことがあります。これはよくある
  未署名アプリの表示で、ウイルスが検出されたという意味ではありません。
  表示された画面で「詳細情報」→「実行」を選ぶと起動できます。
- **`npm run dist`でエラーになる**：ソースコードからビルドする場合の話です。
  Node.jsのバージョンや`npm install`が正しく完了しているか確認してください。

## ソースコードから起動する場合（開発者向け）

シナリオデータの仕様を変更したい、機能を追加したいなど、コードを直接編集したい場合は
こちらの方法で起動できます。

### 動作環境

- Node.js 18以上を推奨

### セットアップと起動

```bash
npm install
npm start
```

### 配布用の実行ファイル（Windows .exe）を作る

```bash
npm run dist
```

`electron-builder`により`dist/`フォルダに、インストーラー版とポータブル版の`.exe`が生成されます。

### GitHub Actionsによる自動ビルド

このリポジトリの`.github/workflows/build.yml`により、バージョンタグ（例: `v1.0.0`）を
pushすると自動でWindows向けの実行ファイルがビルドされ、GitHubの「Releases」ページに
添付されます。

```bash
git tag v1.0.0
git push origin v1.0.0
```

### ランタイムの自動テスト

```bash
npm run test:engine
```

サンプルプロジェクトをテスト自身が一時的に生成して検証するため、追加の準備は不要です。

### フォルダ構成

```
main/              Electronメインプロセス（ウィンドウ管理・ファイルI/O・書き出し処理）
renderer/          エディタ本体のUI（HTML/CSS/JS）
player-template/   書き出されるノベルゲーム本体（ランタイム/セーブ機能を含む）
build/             アプリのアイコン（icon.png / icon.ico）
.github/workflows/ GitHub Actionsでの自動ビルド設定
test/engine.test.js  ランタイムの自動テスト
```

### シナリオデータの仕様（拡張の参考に）

プロジェクトは`project.json`として保存され、シーンはコマンドの配列で構成されます。
対応コマンド: `text`（セリフ/地の文）, `bg`（背景）, `char_show`/`char_hide`（立ち絵）,
`bgm_play`/`bgm_stop`, `se_play`, `voice_play`, `set_var`（変数操作）, `choice`（選択肢分岐）,
`jump`（条件付きシーン移動）, `end`（終了）。
